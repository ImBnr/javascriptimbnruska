1. W jaki sposób można określić właściwość danego obiektu (dwa sposoby wraz z przykładami)?

  • kropka: object.property np. car.color
  • nawiasy: object['property'] np. car['color']

2. W jaki sposób można odwołać się do pól (właściwości) i metod?

Poprzez kropkę lub nawiasy kwadratowe:
object.property lub object.method()
object['property'] lub object['method']()

3. Wymień cechy charakterystyczne konstruktora

  • Tworzy i inicjalizuje nowy obiekt
  • Wywoływany automatycznie przy użyciu new
  • Może przyjmować parametry do ustawienia właściwości

4. Konstruowanie obiektu na podstawie przykładu

function Person(name, age, city) {
  this.name = name;
  this.age = age;
  this.city = city;
  this.greet = function() { console.log("Hello!"); }
}
const user = new Person("Jan", 25, "Warsaw");

5. Znaczenie słowa this. Jak oddzielamy pola oraz metody?

this odnosi się do aktualnego obiektu.
Pola i metody oddzielamy kropką: object.property lub object.method()

6. Konstruktor w JS na podstawie przykładu wraz z opisem

function Car(model, year) {
  this.model = model; // właściwość
  this.year = year; // właściwość
  this.start = function() { console.log("Start"); } // metoda
}
const myCar = new Car("Toyota", 2020);
Konstruktor tworzy nowy obiekt myCar i inicjalizuje jego właściwości i metody.

7. Znaczenie słowa kluczowego new wraz z przykładem

new tworzy nową instancję obiektu i wywołuje konstruktor.
Przykład: const obj = new Car("Honda", 2019);

8. Znaczenie słowa kluczowego prototype wraz z przykładem i opisem

prototype pozwala dodawać właściwości i metody wspólne dla wszystkich instancji danej klasy.
Przykład:
Car.prototype.drive = function() { console.log("Driving"); };
const car1 = new Car("Ford", 2021);
car1.drive(); // "Driving"
