Rodzaje pętli

Pętla for

Konstrukcja:

for(inicjalizacja; warunek; zmiana)
{
    instrukcje;
}

Opis:

Pętla wykonywana określoną liczbę razy. Najczęściej stosowana, gdy znamy liczbę powtórzeń.

Schemat blokowy:

Start
  |
Inicjalizacja
  |
Warunek?
 /    \
TAK   NIE
 |      |
Instr. Koniec
 |
Zmiana
 |
Powrót do warunku

Pętla while (kontrolowane wejście)

Konstrukcja:

while(warunek)
{
    instrukcje;
}

Opis:

Najpierw sprawdzany jest warunek. Jeśli jest fałszywy, pętla nie wykona się ani razu.

Schemat blokowy:

Start
  |
Warunek?
 /    \
TAK   NIE
 |      |
Instr. Koniec
 |
Powrót do warunku

Pętla do while (kontrolowane wyjście)

Konstrukcja:

do
{
    instrukcje;
}
while(warunek);

Opis:

Instrukcje wykonują się co najmniej jeden raz. Warunek sprawdzany jest na końcu pętli.

Schemat blokowy:

Start
  |
Instrukcje
  |
Warunek?
 /    \
TAK   NIE
 |      |
Powrót Koniec
